# دليل تسليم أكاديمية آفاق

## الروابط

- الموقع: `https://afaaqinstitute.com/`
- لوحة الإدارة: `https://afaaqinstitute.com/admin/`
- فحص الخدمة: `https://afaaqinstitute.com/api/health/`

غيّر كلمة مرور المدير المؤقتة فور أول تسجيل دخول، ولا تشارك حساب المدير بين أكثر من شخص.

## إدارة المحتوى

من القائمة العربية في لوحة الإدارة:

- **الكورسات:** افتح «الكورسات» لإضافة أو تعديل الوصف والفئة والعمر والمستوى والأهداف والنتائج والمدة ومدة الحصة. استخدم «ظاهر في الموقع» للتحكم في النشر و«كورس مميز» للعرض في الرئيسية.
- **الأسئلة الشائعة:** افتح «الأسئلة الشائعة» وعدّل السؤال والإجابة والترتيب. إلغاء «ظاهر في الموقع» يخفي السؤال دون حذفه.
- **آراء العملاء:** أضف الرأي الحقيقي فقط، وراجعه ثم فعّل «معتمد للنشر». لا يظهر أي رأي غير معتمد في الموقع.
- **طلبات الحصة التجريبية:** راجع بيانات الطالب وولي الأمر، ثم حدّث الحالة وملاحظات الفريق. بيانات IP والمتصفح تقنية ومخفية داخل قسم مطوي.
- **رسائل التواصل:** راجع الرسالة، وحدّث حالتها بين جديدة وقيد المتابعة وتم الرد ومغلقة، واكتب ملاحظات الفريق عند الحاجة.
- **إعدادات الموقع:** عدّل الهاتف وواتساب والبريد وأوقات التواصل من «إعدادات الموقع». لا تضف سجلًا ثانيًا.

## التشغيل والتحديث

فحص الخدمات الخاصة بآفاق فقط:

```bash
sudo systemctl status afaaqinstitute-backend.service afaaqinstitute-frontend.service --no-pager
sudo journalctl -u afaaqinstitute-backend.service -u afaaqinstitute-frontend.service -n 100 --no-pager
```

تحديث المشروع من الفرع الرئيسي:

```bash
sudo AFQ_PROJECT_ROOT=/var/www/afaaqinstitute /var/www/afaaqinstitute/deploy/update.sh
```

لا تعدّل أو تعِد تشغيل خدمات أي مشروع آخر على الخادم.

## النسخ الاحتياطي

- الموقع: `/var/backups/afaaqinstitute`
- الجدول: نسخة PostgreSQL مضغوطة يوميًا مع الاحتفاظ بسبعة أيام.
- حالة المؤقت: `sudo systemctl status afaaqinstitute-backup.timer --no-pager`
- تشغيل نسخة فورية: `sudo systemctl start afaaqinstitute-backup.service`

أمر الاستعادة التالي للتوثيق فقط؛ استخدم قاعدة اختبار باسم مختلف ولا تنفذه على قاعدة الإنتاج دون خطة استعادة معتمدة:

```bash
sudo -u postgres pg_restore --clean --if-exists --dbname=TARGET_DATABASE /var/backups/afaaqinstitute/ARCHIVE.dump
```
