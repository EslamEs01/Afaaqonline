# أكاديمية آفاق — Afaaq Academy

واجهة موقع عربية كاملة لأكاديمية آفاق، مبنية بهوية أصلية مستخرجة من الشعار الرسمي، ومهيأة للربط لاحقًا بباك إند Django.

## التقنية

- Vinext / React 19 / TypeScript
- Tailwind CSS 4 مع نظام تصميم مخصص
- Alexandria Variable محليًا؛ لا يعتمد الخط على CDN
- RTL عربي كامل ومتجاوب مع الهاتف والتابلت والكمبيوتر
- صور WebP محلية محسّنة، دون hotlinks خارجية

## التشغيل

```bash
npm install
npm run dev
```

يفتح المشروع افتراضيًا عبر خادم التطوير الذي يظهره الأمر.

## الصفحات

- `/` الرئيسية
- `/about` من نحن
- `/courses` البرامج والكورسات مع تصفية تفاعلية
- `/courses/[slug]` ثلاث عشرة صفحة كورس مستقلة
- `/private-lessons` الدروس الفردية
- `/free-trial` نموذج حجز متعدد الخطوات
- `/contact` تواصل معنا
- `/faq` الأسئلة الشائعة
- `/privacy` سياسة الخصوصية
- `/terms` الشروط والأحكام
- صفحة 404 مخصصة

## ملاحظات الربط بالباك إند

نماذج الحصة التجريبية والتواصل تعمل تفاعليًا في نسخة الفرونت الحالية، لكن الإرسال فيها محلي لأغراض اعتماد التصميم. عند ربط Django يجب استبدال دوال الإرسال بطلبات API آمنة مع CSRF، والتحقق من البيانات في الخادم، ورسائل نجاح وفشل مبنية على استجابة حقيقية.

نصوص آراء أولياء الأمور المعروضة حاليًا توضيحية لاعتماد شكل القسم، ويجب استبدالها بآراء حقيقية معتمدة قبل النشر النهائي.
